# 轻舟 macOS 版本记录

## 0.6.9 网络稳定性与诊断更新

- 汇总桌面核心锁外检测、断开优先调度、旧结果丢弃、DNS/出口分级恢复与有界重试。
- Android 修复虚拟 DNS 路径与严格 TLS 健康检查，四端源码统一为 0.6.9。
- 增加定期诊断、节点质量与检测时间；优化 macOS 界面、测速布局稳定性和日志跟随。
- 本地自动化、历史 Android 真机结果及公开包的签名限制分别见 [0.6.9 发布说明](../../docs/RELEASE_0.6.9.md)。

## 0.6.5 源码快照

- 提供原生窗口、菜单栏、订阅与分流规则、私有网络接入、流量与诊断界面。
- 包含网络切换与睡眠恢复、后台刷新控制及消息读取内存修复。
- 订阅兼容格式改为通过 `list=shadowrocket` 显式选择，移除服务商域名判断。
- 本地构建默认使用 ad-hoc 签名，分发身份由构建者显式配置。
- 源码测试与完整安装包、系统权限、真实联网验收分别记录；此快照不附带安装包。
