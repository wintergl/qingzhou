# 轻舟 · Windows

WPF 原生界面 + Rust 核心 + Mihomo TUN，aTrust 认证由 Go 适配器处理。目标为 Windows x64，自包含 zip 内附 .NET 运行时，不需要 WebView2。

## 运行与数据

使用 Windows 10 1809 及以上或 Windows 11。解压整个安装包后运行 `Qingzhou.exe`，按提示授予管理员权限以创建 TUN。最小化或点关闭会收进右下角托盘，窗口及任务栏按钮隐藏，VPN 保持连接。点击托盘图标、右键选择“打开轻舟”，或再次双击程序，会恢复同一个窗口。真正退出时，右键托盘选择“退出轻舟（断开连接）”。包内的 [README.txt](README.txt) 提供离线运行说明、测试建议和已知限制。

订阅、设置和日志沿用 `%APPDATA%\@split-vpn\desktop`。界面偏好、DPAPI 加密凭据和网关证书指纹放在 `%LOCALAPPDATA%\Qingzhou`。日志页可导出脱敏诊断。

## 分流规则

规则表分别显示地址、匹配范围和 VPN / 直连出口。添加时先选出口，再填域名、IP、网段或网址；核心负责格式检查，保存失败时弹窗保留输入。可编辑现有规则并直接换出口。

填写示例、优先级与默认策略的区别统一见 [项目 README](../../README.md#如何填写分流规则)。旧 VPN 规则继续保留，新增直连规则独立保存。

## 私有网络

支持 aTrust 登录、验证码、网关要求的密码修改、授权资源和 TCP 分流。使用系统分流需要开启 TUN 并使用规则模式；EasyConnect 尚未接入。

服务器明确确认改密后才更新已记住的凭据。提交结果不确定时暂停自动读取旧密码，需先尝试新密码登录。完整认证协议与安全边界统一见 [接入适配器 README](../../packages/company-vpn/README.md)。

托盘保持一个图标，菜单显示 VPN 状态并提供打开和退出入口；收起后保留原有页面和窗口状态。退出时移除图标并释放事件订阅、菜单与图标资源，随后停止认证服务和 VPN 核心。真实 Windows 托盘、窗口、DPAPI、管理员权限、接入网关和隧道联网需实机验收；本机假服务回归只能验证状态与生命周期处理。

颜色与 macOS 一致：个人 VPN 已连接时帆变蓝，私有网络已连接时船身变绿；两者独立变化，未连接时保留中性轮廓。连接/断开中显示省略号，异常显示叹号，首次读取或状态未知显示问号。图标跟随任务栏明暗模式，悬停和菜单分别显示两路状态。业务检测失败不改变已确认的连接颜色；核心状态读取失败时取消相应颜色，重新确认后恢复。每次变色替换并释放旧图标，不累积缓存。

## 网络切换与后台省电

监听网卡地址、默认路由与 Wi-Fi 连接事件，切换 Wi-Fi / 有线、断网后恢复、睡眠唤醒时通知共享核心。连续变化会合并，过滤自身 TUN 网卡与路由变化；核心等待网络稳定后恢复连接，失败会有限重试，总览显示等待、恢复中或失败，并提供手动重试。主动断开会取消恢复意图，后来的网络通知不会重新连接。

窗口最小化、收进托盘、屏幕关闭或系统休眠时暂停流量和日志自动读取；恢复显示后补读流量。正常显示时每 2 秒刷新，Windows 节电模式开启后改为每 5 秒。日志只在日志页可见且开启“跟随”时刷新。最小化和关闭窗口均继续保持连接，从托盘菜单退出才会停止连接。

核心优先响应系统通知，保留低频的物理网络检查；通知注册失败时保留更频繁的兜底检查。休眠与节电状态也传给核心，减少无用检查。网络切换后清除旧的连接检测结果，迟到结果不会覆盖新网络的状态。

已验证共享核心与 Windows 状态逻辑、交叉编译，以及原生结构体布局；Wi-Fi / 有线切换、真实睡眠唤醒、Windows 节电通知与实际耗电量仍需在 Windows 电脑上测试。

## 开发

打包、依赖与测试命令见 [开发指南](../../docs/DEVELOPMENT.md#windows)。默认产物是 `apps/windows/release/Qingzhou-<版本>-windows-x64.zip`；源码版本由 `Qingzhou/Qingzhou.csproj` 定义。

脚本拒绝覆盖已有目录或 ZIP，重复打包时用 `SPLITVPN_WINDOWS_RELEASE_DIR` 指定新目录。当前源码构建标记为 `0.6.5+2026102001`，Windows 文件版本为 `0.6.5.1020`；Windows 实机运行仍需单独验收。

更新整包或只替换核心时，先从托盘菜单选择“退出轻舟（断开连接）”，再替换文件。订阅和设置沿用原数据目录。安装包的第三方声明与对应源码事项见 [第三方依赖说明](../../docs/THIRD_PARTY.md)。
