轻舟 Windows 测试版
==================
版本：0.6.5，构建 2026102001

运行要求
- Windows 10 1809 及以上，或 Windows 11（64 位）
- 不需要安装 WebView2，也不需要安装 .NET（运行时已打包在 Qingzhou.exe 内）

使用
1. 把整个文件夹解压到一个固定位置（不要直接在压缩包里运行）。
2. 双击 Qingzhou.exe，系统会请求管理员权限（创建 TUN 虚拟网卡需要）。
3. 首次运行如被 SmartScreen 拦截：点“更多信息” -> “仍要运行”（测试版未做代码签名）。
4. 最小化或点窗口右上角关闭，会收进右下角托盘并从任务栏消失；VPN 保持连接。
5. 点击托盘图标，或右键选“打开轻舟”，恢复原来的窗口与任务栏按钮；再次双击程序也会打开已有窗口。
6. 真正退出时，右键托盘图标选“退出轻舟（断开连接）”，会停止内核并清理本次连接。
7. 收进托盘后流量和日志自动刷新暂停，恢复窗口后继续。
8. 蓝帆表示个人 VPN 已连接，绿船表示私有网络已连接，两种颜色独立显示；连接中显示省略号，异常显示叹号，状态未知显示问号。
9. 图标随 Windows 任务栏的浅色/深色模式切换；悬停可查看两路连接状态。

数据位置
- 订阅、设置、日志：%APPDATA%\@split-vpn\desktop
- 应用日志：%APPDATA%\@split-vpn\desktop\logs\app.log
- 内核日志：%APPDATA%\@split-vpn\desktop\logs\mihomo.log
- 界面外观、加密保存的 ipdata 密钥与接入账号、接入网关证书指纹：%LOCALAPPDATA%\Qingzhou

建议测试项
- 中文显示、浅色/深色外观切换
- 添加订阅、更新订阅、自动更新间隔、节点列表显示
- 选择节点后连接；访问 google.com / chatgpt.com（走 VPN），访问 baidu.com（直连）
- 切换节点、收藏节点、节点组编辑、断开、再连接
- 节点测速、UDP 检测、风险检测（需先在“诊断与风险”配置 ipdata 密钥）
- 分流规则：先选“VPN / 直连”，再填写域名、网址、IP 或网段；可编辑地址、换出口，保存失败保留输入
- 示例：example.test 匹配域名及子域，https://api.example.test/path 提取域名，10.0.0.8 匹配单个 IP，10.0.0.0/24 匹配网段
- “未知流量走 VPN / 直连”只决定没有命中规则的流量；明确填写的规则按所选出口处理
- 私有网络：密码到期时填写旧密码、新密码和确认密码；被私有网络规则拒绝后可重填，成功后继续短信/动态口令认证
- 接入密码：仅在服务器确认改密后更新已勾选记住的密码；取消或结果不确定时不会自动反复提交改密
- 流量页实时连接、日志页读取与导出脱敏诊断
- 设置里勾选“登录 Windows 后启动”，重新登录后是否自动启动并连接
- 连着 VPN 切换 Wi-Fi / 有线，或切换到同地址网段的另一个 Wi-Fi，确认状态进入恢复中并自动恢复
- 暂时关闭 Wi-Fi / 拔掉网线，确认显示等待网络；恢复网络后自动连接
- 等待网络或恢复失败时点“断开 VPN”，再恢复网络，确认不会自动重连；失败时也可手动重试
- 睡眠后唤醒，确认恢复原有连接；主动断开后睡眠唤醒，确认仍保持断开
- 最小化或关闭屏幕时，确认 VPN 保持连接；重新显示窗口后流量恢复更新
- 开启 Windows 节电模式，确认流量页显示每 5 秒更新；正常模式每 2 秒更新
- 最小化或关闭窗口后任务栏按钮消失，托盘图标仍在，VPN 继续工作
- 从托盘或再次双击程序打开同一个窗口，保留原有页面、窗口大小和最大化状态
- 托盘选择退出后网络是否恢复正常（无残留虚拟网卡、DNS 正常），托盘图标和相关进程退出
- 重启 Windows 资源管理器后托盘图标是否恢复；注销与系统关机是否正常退出
- 分别连接个人 VPN、私有网络与同时连接，确认蓝帆和绿船独立变化；切换任务栏明暗模式检查图标

已知限制（测试版）
- 私有网络需要开启 TUN 并处于规则模式；真机登录、隧道和分流尚未在 Windows 上验收。
- 托盘关闭、恢复和退出逻辑已通过隔离回归；图标显示、资源管理器重启、Windows 注销与真实网络清理仍需实机验证。
- 本包已通过交叉编译和隔离回归；Windows 原生通知、真实网络切换与耗电量尚待实机验证。
- 此包用于本地测试；公开发布前仍需完成第三方声明与对应源码整理。

遇到问题请在“日志”页导出脱敏诊断，或把 logs 文件夹里的 app.log、mihomo.log 发回。
