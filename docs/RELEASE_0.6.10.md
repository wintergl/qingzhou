# 轻舟 0.6.10 · 网络稳定性与连接诊断更新

本次汇总 0.6.5 之后的修复，四端源码版本统一为 0.6.10。继续以预发布提供，自动构建和真实设备验收分别记录。

## 网络不稳定相关修复

- **桌面检测卡住、操作迟迟无响应**：测速、诊断和后台采样移出核心共享锁，状态读取使用快照；断开优先调度，取消排队的旧操作。已经进入系统授权或配置事务的操作仍须等安全收尾。
- **断开或切网后状态回跳**：按连接代次、配置版本与进程核对异步结果，丢弃旧连接的检测、启动结果和快照，避免界面重新显示为已连接。
- **内核运行却无法上网**：分别检查控制器/TUN、系统 DNS 和指定节点的 HTTPS 路径，界面区分 DNS 异常与 VPN 出口异常。短暂失败先复查，避免一次波动触发恢复。
- **恢复时反复重启、已有连接受影响**：DNS、出口和控制器故障采用不同恢复步骤；同一路径修复保留已有连接，配置修复加入冷却和次数预算。只有物理路径变化时才有界清理可确认的旧连接，保留私有网络和未知连接。不自动改换手动固定的节点。
- **Android DNS 与实际应用路径不一致**：系统 DNS 改走虚拟入口，经现有桥接送到 Mihomo 内部 DNS 出站，保留 Fake-IP 与域名策略。健康检查先解析 DNS，再用解析出的地址进行严格域名和证书校验的 TLS 检查；DNS/TLS 失败共享预算，控制器故障独立处理，并设置总超时。

## 检测与界面

- 桌面连接稳定后定期检测连通性和站点响应；休眠、切网和批量测速期间暂停或延后，省电时降低频率。
- 节点区分未测、可用、超时、未连通、过期和同名冲突；失败不再显示为 0 ms，展示检查时间、来源和逐条进度，可取消批量测速。
- 站点 HTTP 403/429/451 显示为访问受限，不当作连接超时；响应耗时不代表下载带宽或业务权限。
- macOS 更新页面层级、浅深色与小窗口布局，修复测速时列表高度/滚动位置跳动，以及日志跟随更新不到底或上下滑动的问题。Windows 同步诊断状态、时间和节点质量展示。

## 验证与边界

本次本地回归：Rust 143 项通过、1 项既有真实内核测试忽略；Clippy 无警告；JSON 行 RPC 36 项通过；macOS 构建通过、127 项测试中 126 项通过、1 项条件导出测试跳过；Windows 模拟运行状态 32 项通过；Android 单元测试 45 项通过；公开仓库发布脚本 15 项通过。核心检查使用隔离目录，未启动真实 VPN、修改系统 DNS/路由或替换已安装应用。

Android 此前 0.6.6 同一 DNS 修复已完成 Wi-Fi/移动网络互切、短时熄屏唤醒的真机验证，并得到实际对话恢复正常的用户确认；长时间锁屏和深度 Doze 尚未验收。探针本身不覆盖完整 TUN/桥接路径，不能代替设备实测。0.6.10 安装包需另行验证。

桌面真实节点抖动、DNS 故障、切网、睡眠唤醒、私有网络共存与系统授权仍需实机观察；Windows 原生窗口、iOS 真机联网和实际耗电没有因自动构建通过而视为已验收。

Windows 打包另补齐托盘图标来源清单，并在依赖构建前检查全部 32 个图标、256 个 PNG 帧。0.6.9 云端候选未完成发布；最终以 0.6.10 发布，不移动旧标签。

## 下载与升级

- GitHub Actions 全部通过后，发布页附 macOS Apple Silicon/Intel 临时签名 ZIP、Windows x64 未签名 ZIP、Android arm64 调试 APK，以及对应源码和 SHA-256 清单。
- iOS 附件是未签名的模拟器应用，不能直接安装到 iPhone；真机需要自行配置签名构建。
- macOS 自动包未获 Developer ID 签名或 Apple 公证；Android 自动包使用 CI 调试证书，与既有本地包未必同签名。不要为覆盖升级而直接卸载清数据，先核对签名并备份配置。
- 沿用原有用户数据目录与设置格式，无需主动清理订阅、分流规则或钥匙串。
