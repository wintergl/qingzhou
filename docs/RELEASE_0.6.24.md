# 轻舟 0.6.24

同步 0.6.10 之后的四端源码和 2026-10-30 的 ISP 线路改进。GitHub 自动包继续作为预发布，保留原有用户数据目录与设置格式。

## 线路与桌面

- 增加静态 ISP 出口设置、上游线路扫描、性能比较、历史记录和日常连接流程。配置与开关置顶，当前线路、所属订阅和备用线路直接可见。
- 每个启用订阅最多保留两条完整验证过的备用。当前客户端维护的 ISP 连接连续三次出口检测异常后，优先复核另一订阅的备用，再尝试切换；两次自动尝试至少间隔五分钟。
- 备用预检失败保留原连接；切换后实际出口不符时恢复原线路。取消、断开、换网及并发用户操作使旧结果失效。
- 切换区持续显示原线路、目标线路和处理步骤；区分响应失败、出口查询失败与出口不符，失败保留内联反馈和重试入口。
- 同步桌面诊断、流量展示、应用分流和省电维护改进；自动换线不主动启动 VPN，也不自动退回直连。

## 移动端

- 补齐订阅、节点、规则、诊断和管理界面，以及 aTrust 认证、挑战交互、资源刷新和 TCP 接入。
- 密码进入系统安全存储；认证会话、SID、cookie 和回调只留内存。iPhone 通过已有 Packet Tunnel 与组合 Go 运行库承载接入；Android 复用既有 VPN 数据面。
- iPhone BALANCE 按目标稳定分配节点，建连失败时尝试其他节点。移动端未增加桌面常驻扫描或后台自动换线。

## 公开源码与构建

- 保留公开仓库的空配置、示例地址、显式订阅格式和本机签名配置；不导入私人 Git 历史、用户数据、诊断日志、签名材料或本地安装包。
- 更新 GitHub 构建入口，准备 Android CompanyCore AAR 与 iOS Libbox + companymobile 组合框架，提供匹配的上游补丁源码、移动构建工具与许可证。
- 源码隐私检查及 Gitleaks 扫描未发现告警。自动检查的结果与范围见[源码说明](SOURCE_SNAPSHOT.md)。

## 下载和验收范围

全部构建任务成功后发布 macOS Apple Silicon / Intel 临时签名 ZIP、Windows x64 未签名 ZIP、Android arm64 调试 APK、iOS 未签名模拟器应用及对应源码和 SHA-256 清单。

iOS 模拟器包不能安装到 iPhone。GitHub 的 macOS 包未使用 Developer ID 签名或 Apple 公证，Android 包使用 CI 调试证书，覆盖升级前应核对签名并备份配置，勿为安装而直接卸载清数据。

自动构建和隔离回环测试不代表真实账号、设备联网、系统权限、切网、睡眠恢复、业务会话或长期耗电已验收。移动端 aTrust 当前限 IPv4 TCP，UDP / L3 不在本次实现范围。
