# 源码快照说明

此版本提供四端应用源码、共享 Rust 核心、aTrust 适配补丁、测试、构建脚本与应用图标。仓库从独立源码快照建立，不包含此前的提交历史或远程仓库配置。

源码中不附带历史诊断、私人截图、聊天原稿、日志、用户数据、签名身份、设备描述文件、安装包、预编译运行内核或 Geo 数据。示例使用保留域名与测试地址；四端的通用包标识和兼容配置键保持原样。

订阅格式通过 `list=shadowrocket` 显式选择，不绑定某个订阅服务商域名。macOS 本地构建默认使用 ad-hoc 签名，iOS 默认团队编号为空，个人签名配置保存在被忽略的本机文件中。

## 检查方式

在仓库根目录运行：

```sh
python3 scripts/check_public_source.py
```

脚本检查 Git 跟踪和未忽略的源码文件，拦截本机用户路径、常见令牌与私钥头、非示例邮箱、签名材料、安装包和指向其他位置的软链接。它只报告位置与类别，不输出匹配值。检查不能证明所有文本、图片或编码内容都不含敏感信息；新增截图、第三方资源及安装包仍需分别审核。
